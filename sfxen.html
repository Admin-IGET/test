More information
Every time a UvikOS update is released, the UvikOS self-extracting archive file changes. As a result, Windows Defender treats it as a completely new file and incorrectly identifies it as malware.

To have the detection removed, we (the developers) must submit the file through Microsoft's WDSI website and request a review (and subsequent removal) of the detection.

However, the removal of the detection can take up to a day. Until it is removed, Windows Defender may continue to flag the file on any system.

How to Download UvikOS

Welcome to the UvikOS download guide.
This guide will walk you through downloading UvikOS using the self-extracting archive. It also includes images.

WARNING: Windows Defender may incorrectly identify the UvikOS self-extracting archive as malware in certain situations. If you encounter this error, try downloading UvikOS again later.

If you are using Microsoft Edge, click .

First, download the UvikOS self-extracting archive: Download.

Because UvikOS is not commonly downloaded, Microsoft Edge may show a ”this file isn't commonly downloaded“ warning. To bypass this warning, click the ... button, then click Keep, then click the ▼ button next to the Delete button, and finally click Keep anyway.

When the download finishes, open the downloaded file.

Because UvikOS isn't commonly downloaded and isn't digitally signed, a SmartScreen warning may appear. To bypass this warning, simply click More info, then click Run Anyway.

Picture:

Then, the UvikOS self-extracting archive will open. Click Continue to extract the files needed to install UvikOS. The files will be extracted into a folder named “UvikOS” in the same folder as the self-extracting archive. Once the extraction is complete, click OK to start the UvikOS installer.

Picture:

The program will open the UvikOS installer. If you don't see it, check the taskbar (bottom panel) or open the Install UvikOS file from the opened folder. Then go through the UvikOS installer as per normal.

Picture:

If you want to save storage space, move the “Start UvikOS” file to another folder, then delete the downloaded file (UvikOS_self-extracting_archive.exe) and the extracted folder.
